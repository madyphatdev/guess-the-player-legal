Privacy Policy

Effective Date: September 2026 • Last Updated: September 2026

1. Overview

Guess The Player ("we", "our", or "the application") is committed to protecting your privacy. This Privacy Policy details how we handle information, API tokens, and user credentials.

2. Data Storage & Local Processing

Guess The Player functions as a local content creation tool. All API tokens (including Google Gemini API keys, YouTube OAuth credentials, TikTok Access Tokens, and Meta Page Access Tokens) are stored locally on your own machine in your private environment file (.env.local) or in your browser's local state. We do not collect, transmit, or sell your personal credentials to any external servers.

3. Third-Party API Integrations

When you explicitly trigger automated rendering and publishing actions, data (such as the generated video file, title, hashtags, and description) is transmitted directly to the authorized third-party platform API endpoints:

  • Google / YouTube Data API v3
  • TikTok Content Posting API v2
  • Meta Graph API for Facebook Reels

4. Data Security

All network communications with third-party APIs utilize industry-standard Transport Layer Security (TLS/HTTPS) encryption to protect your data in transit.

5. Contact

If you have any questions or privacy inquiries, please contact the developer via GitHub.
