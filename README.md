# Guess The Player - Legal Documents

Standalone static website hosting the official **Terms of Service** and **Privacy Policy** for Guess The Player Studio.

## Deploying to GitHub Pages (1 Minute)

1. Create a new repository on GitHub (e.g. `guess-the-player-legal`).
2. Run these commands inside this `legal-pages` directory:

```bash
cd legal-pages
git init
git add .
git commit -m "feat: initial legal pages"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

3. On GitHub, go to **Settings** -> **Pages** -> Select branch `main` and folder `/ (root)` -> Click **Save**.
4. Your live URLs will be:
   - **Terms of Service**: `https://<YOUR_USERNAME>.github.io/<YOUR_REPO_NAME>/terms.html`
   - **Privacy Policy**: `https://<YOUR_USERNAME>.github.io/<YOUR_REPO_NAME>/privacy.html`
